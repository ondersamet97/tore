# Known limitations

- Individually tested preview candidate; no multi-user isolation, cloud sync, hosted service or availability guarantee. Only local loopback use is intended.
- Records are user-reviewed statements, not verified truths or scientific ideology measurements. AI text retains its original attribution even when endorsed later.
- No automatic extraction or topic clustering is claimed. Users select a source excerpt and decide its meaning and status.
- Manual continuation does not read a third-party chat or verify the model that produced a pasted reply. Destination and model labels are user declarations.
- Malformed structured replies are retained for correction. Parsing alone does not establish truth. Source references still need validation.
- Context selection is narrow. Excluded, historical, draft or unreviewed material is not automatically shared. Inspect the complete preview before copying.
- Source archives and record backups are different scopes. Keep the original conversation archive; a record backup is not a full backup of every Töre store.
- Legacy opinion cards remain available. Migration preserves endorsement but leaves unknown currency/priority unknown. It is not an automatic update of personal ideology.
- Existing ChatGPT sign-in and OpenRouter code has simulated/contract coverage; no new live account or paid-model verification is claimed. The topic flow needs neither.
- The older local-model implementation is disabled. This preview does not run, download or benchmark local models.
- Installation requires a development toolchain and can use the network. Clean-source verification on the developer Mac shares system tools and caches; it is not a fresh operating-system certification.
- From 0.11.0-rc.4 the original code is offered under PolyForm Noncommercial 1.0.0; the project is source-available, not open source. The source was first published at the owner's instruction with 0.12.0 (2026-11-16), as an allowlisted snapshot without private Git history. No legal review or licence-compatibility certificate is claimed.
