# Contributing

Thank you for looking at töre.

**Issues and ideas are welcome.** Bug reports, questions and suggestions help, especially with a short description of what you did and what you expected. Please do not paste real conversations or personal notes into an issue; use the synthetic files in `fixtures/`.

**Code contributions are not being merged yet.** töre is offered under the AGPL with a separate commercial licence, which requires the project to hold the rights to all of its original code. Until a contributor agreement is in place, pull requests cannot be accepted. If you want to contribute code, open an issue first so we can talk about it.

töre is developed with AI coding tools, and this is stated openly. If you send a patch later, please say whether tools helped you write it.
