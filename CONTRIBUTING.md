# Contributing

Thank you for looking at töre.

**Bug reports and questions** go to [töre on LinkedIn](https://www.linkedin.com/company/tore-app/) or to the email address on the [contact page](https://ondersamet97.github.io/kim.html). A short description of what you did and what you expected helps. Please do not send real conversations or personal notes; use the synthetic files in `fixtures/`.

**Code contributions are not being merged yet.** töre is offered under the AGPL with a separate commercial licence, which requires the project to hold the rights to all of its original code. Until a contributor agreement is in place, pull requests cannot be accepted. If you want to contribute code, write first through the same contact so we can talk about it.

töre is developed with AI coding tools, and this is stated openly. If you send a patch later, please say whether tools helped you write it.
